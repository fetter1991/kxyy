# 开心元元个人粉丝站 · 页面功能与交互逻辑图谱

> 项目类型：纯静态多页面站点（HTML + CSS + 原生 JS）
> 站点域名/标题：开心元元的个人粉丝站
> 全局架构：AJAX 无刷新页面切换（`nav-switch.js`）+ 全局导航栏音乐播放器（`nav-player.js`）+ 公共 UI（`common-ui.js`）

---

## 一、全局共享结构（所有页面共用）

每个页面 HTML 顶部均包含相同的外壳，不随内容切换而重建：

```
┌─────────────────────────────────────────────────────────────┐
│  Navbar（固定导航栏）                                       │
│  ┌────────┐  ┌────────────────────────────┐  ┌──────────┐   │
│  │ Logo   │  │ 相册 素材库 个人资料 视频 │  │ [音乐]   │   │ 
│  │ 首页   │  │ 成长历程 留言              │  │ (汉堡)   │   │
│  └────────┘  └────────────────────────────┘  └──────────┘   │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┴──────────────────────┐
        ▼                                            ▼
┌──────────────────────┐                    ┌──────────────────┐
│  #pageContainer      │                    │ 全局浮层（不随   │
│  （页面内容，切换时  │                    │ 切换重建）       │
│   被 AJAX 替换）     │                    │ · lightbox 灯箱 │
│                      │                    │ · 导航栏播放器   │
└──────────────────────┘                    │ · back-to-top   │
                                            └──────────────────┘
```

### 全局交互线路图

```
用户点击 nav-link
      │
      ▼
nav-switch 拦截默认跳转 ──► fetch 目标页 HTML
      │                         │
      │                         ▼
      │               showLoading() 打字机动画（≈0.8s）
      │                         │
      ▼                         ▼
cleanupPage() ◄──── 清理上一页定时器/监听器/弹窗
      │
      ▼
替换 #pageContainer 内容 + 重建浮层(lightbox/workModal/growthModal)
      │
      ▼
更新标题 / 导航 active / 滚动置顶 / history.pushState
      │
      ▼
调用目标页初始化函数（INIT_MAP）→ hideLoading()
```

**全局播放器（nav-player）**：点击 🎵 按钮 → 图标旋转 360° 并 cross-fade 变头像 → 左右面板双向展开（上一首/播放-暂停/下一首 + 歌名-歌手）。后台 `<audio>` 始终存活，切页音乐不中断。点击播放列表项可切歌；播放结束自动下一曲。

**公共 UI（common-ui）**：导航栏滚动毛玻璃、回到顶部按钮（滚动 >300px 显隐）、移动端汉堡菜单展开/收起。

## 三、各页面功能与交互逻辑

### 1. 素材库（首页 · `index.html`）

**功能**：以"素材合集"卡片网格展示图库，支持按分类标签筛选；点击合集打开弹窗，弹窗内可切换缩略图、放大查看、批量打包下载。

**数据流**：`galleryData[]`（title / author / filter / cover / desc / images[]）

**交互流程图**：

```
页面加载
  │
  ▼
initGallery()
  │
  ├─ 构建标签栏 [全部/时尚/风格/场景/氛围]
  │     （仅保留数据中存在的分类）
  │
  ├─ render() → 渲染合集卡片网格
  │
  ▼
用户点击 filter-btn（标签）
  │
  ▼
activeFilter 更新 → render() 重新过滤合集列表
  │
  ▼
用户点击 collection-card
  │
  ▼
openCollectionModal() 打开弹窗
  │
  ├─ 左侧大图预览 + 右侧：标签 / 缩略图列表 / 说明 / 下载按钮
  │
  ├─ 点击缩略图 → 切换左侧大图（active 高亮）
  ├─ 点击大图     → openLightbox() 灯箱放大（←/→/Esc 切换关闭）
  └─ 点击下载     → downloadCollection()（JSZip 打包 images[] → 触发下载）
        │
        ▼
  弹窗关闭：关闭按钮 / 点击遮罩 / Esc
```

**灯箱（gallery 版）键位**：`←` 上一张 · `→` 下一张 · `Esc` 关闭。

### 3. 视频（`pages/video.html`）

**功能**：按"专辑"分组的视频播放器。PC（≥1024px）使用数字分页胶囊（每页 8 条），小屏（<1024px）关闭分页改为"加载更多"滚动加载。支持专辑切换、播放/暂停、上一首/下一首、进度条拖拽、全屏，以及截图中新增的**播放模式切换**。

**数据流**：`videoAlbums[]` → 每个专辑 `{ name, videos[] }`，视频 `{ title, videoUrl, cover, orientation, desc }`

**页面结构示意**：

```
┌──────────────────────────────────────────────────────┐
│                 视频播放器（主舞台）                    │
│              初始显示“视频播放器”占位文案              │
│                 选中后真正加载 <video>                  │
└──────────────────────────────────────────────────────┘
┌────────────────────┬─────────────────────────────────────┐
│  专辑列表 Tab      │  播放模式切换按钮（顺序/随机/循环） │
│  · 作品集          │                                     │
│  · 日常记录        │  专辑下的视频列表（8 条/页）         │
│  · 国风写真        │  · 封面 + 标题 + 播放态             │
│                    │  · 分页胶囊 / “加载更多”            │
└────────────────────┴─────────────────────────────────────┘
```

**交互流程图**：

```
页面加载
  │
  ▼
initVideo()
  │
  ├─ renderTabs() 渲染专辑 Tab（作品集/日常记录/国风写真）
  │     └─ 溢出时显示左右箭头（scrollBy 滚动 Tab）
  │
  ├─ renderPlaylist() 渲染当前专辑视频列表
  │     │
  │     ├─ 【PC ≥1024】getVisibleVideos() 按页切片 (page-1)*8 ~ +8
  │     │        └─ renderPagination() 数字胶囊（含省略号 …，>7页时）
  │     │
  │     └─ 【小屏 <1024】getVisibleVideos() 取 0~loaded
  │              └─ 末尾"加载更多"按钮（+8，scrollToBottom）
  │
  ▼
用户点击专辑 Tab
  │
  ▼
switchAlbum(i) → page=1 / loaded 重置 → renderTabs + renderPlaylist
  │
  ▼
用户点击播放列表项 / 上一首 / 下一首
  │
  ▼
playVideo(index)
  │  ├─ video.src = item.videoUrl → play()
  │  ├─ 更新标题/描述/播放态高亮
  │  └─ playingIndex 标记
  │
  ▼
播放控件交互
  ├─ 播放/暂停按钮 → video.play()/pause() + 图标切换
  ├─ 进度条点击   → 计算比例 → video.currentTime
  ├─ timeupdate    → 更新进度条 + 当前/总时长
  ├─ 全屏按钮     → requestFullscreen / exitFullscreen
  └─ ended         → 按当前播放模式处理（见下方播放模式）
  │
  ▼
窗口 resize（去抖 200ms）→ 重新判断 PC/小屏 → 重渲染（分页↔加载更多）
```

**分页逻辑（PC）**：`totalPages = ceil(总数/8)`；页码 >7 且远离当前页时折叠为 `…`；上一页/下一页边界禁用。

**播放模式切换（新功能，已确认实现）**：

```
播放模式按钮（顺序 / 随机 / 循环，三态切换）
      │
      ├─ 顺序播放：播放到列表最后一项后停止（不自动续播）
      ├─ 循环播放：播放到最后一项后，从专辑第一项重新开始播放
      └─ 随机播放：专辑内随机抽取下一首（不跨专辑）
```

实现要点：
- `state` 新增 `playMode`（默认 `'order'`），点击模式按钮在 `order → loop → shuffle → order` 间循环切换并刷新图标。
- 下一首逻辑 `nextTrackByMode()`：
  - `order`：索引 +1，到末尾则停止播放并清除播放态。
  - `loop`：索引 +1，到末尾回绕到 0。
  - `shuffle`：在 `[0, len-1]` 内随机取一个不等于当前索引的值。
- `video.addEventListener('ended', …)` 改为调用 `nextTrackByMode()`（顺序模式到末尾则停止）。
- 切换专辑时维持当前 `playMode` 不变。

> **新功能备注**：播放模式切换按钮为本次新增需求（截图标注），已按以上规则实现。

**数据流**：`growthDataExtended[]`（date / title / shortTitle / desc / status / cover / type / content）

│              └─────────────┘                                │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  ◆ 梦的开始 │ 七擒孟获 │ 周年庆 │ … │ 古风出圈             │

│  底部时间轴：短标题 + 钻石导航点，当前点高亮                   │

**交互流程图**：

```

  │
  ▼
initGrowth()
  │
  ├─ _renderGrowthTimeline()
  │     ├─ 渲染全屏 item 列表（每屏一事件，高度=容器高度）
  │     └─ 渲染底部时间轴导航点（diamond + shortTitle）
  │
  ├─ 高亮逻辑 _updateGrowthHighlight(idx)
  │
  ▼
【翻页触发】四选一：
  │
  ├─ (a) 点击时间轴上的时间点 → _scrollToGrowthItem(idx)
  ├─ (b) 滚轮 wheel           → 快速滚动连续切换，单轮最多翻 3 格
  ├─ (c) 键盘 ↑/↓             → 一次按键一次切换，禁用长按连续触发

                   "选中点居中 + 边界固定不偏移" 规则
  │
  ▼
用户点击"查看详情 →"
  │
  ▼
_openGrowthModal(idx)
  ├─ 图文（image + text）
  ├─ type=music  → <audio controls> 音频播放器
  └─ type=video  → <video controls> 视频播放器
        │
        ▼
  关闭：× / 点击遮罩 / Esc → _closeGrowthModal()（暂停音频/视频）
```

**切换方式细节（已确认实现规则）**：

| 触发方式 | 行为 |
|----------|------|
| 时间轴点点击 | 直接定位到该整屏 |
| 滚轮 | 快速滚动连续翻格，**单轮最多 3 格**（累加翻页，取代原 800ms 单格锁定） |
| 键盘 ↑/↓ | 一次按键一次切换；**禁用长按**连续触发（按键锁，直到 keyup 才允许下一次） |
| 页面滚动条拖动 | 拖动后计算当前滚动位置落在哪一整屏，快速定位并高亮对应时间轴点 |

**时间轴自适应规则（来自文本文档，基础版已落地）**：

以移动端 440×956、可见 6 个点、共 12 个点（z1-z12）为例，要求：
- 选中点始终在可见区；左侧无隐藏点时靠左固定，右侧无隐藏点时靠右固定（z5 居中显示 z2-z7）。

```
选中 z1/z2/z3：时间轴靠左固定（z1 在最左）
选中 z5      ：当前点居中（显示 z2-z7）
选中 z10/11/12：时间轴靠右固定（z12 在最右）
```

**核心约束**：
- 无论屏幕大小、无论切换方式，内容必须完整贴合，**不能停在两屏中间**。
- 时间轴长度超过可视区时，必须自适应左右移动，保证当前选中点可见。

**事件类型**：`article`（图文）、`music`（音频）、`video`（视频）、`image`（单图）。

> **新功能备注（成长历程）**：
> 1. 页面滚动条拖动定位、滚轮连续翻格（上限 3）、键盘长按禁用 —— 均为本次新增需求，已实现。
> 2. 时间轴"精确居中 + 边界固定不偏移"的精细计算，**本次先确保自适应可见，暂不做精确居中**，列为后续优化点。

### 6. 留言（`pages/message.html`）

**功能**：翻书式"粉丝留言册"。左侧封面+欢迎页，后续每跨页展示 2 条留言卡片；支持上一页/下一页翻书动画；底部表单可发布留言（存入 `localStorage`，即时上墙）。

**数据流**：内置 `messageData[]` + `localStorage['kaixin_yuanyuan_comments']`

**交互流程图**：

```
页面加载
  │
  ▼
initMessage()
  │
  ├─ _buildSpreads()
  │     ├─ 第0跨页：封面 + 欢迎页（显示留言总数）
  │     └─ 每 2 条留言 → 1 跨页（左+右）
  │          不足则补空页 / 期待留言页
  │
  ├─ _renderBook() 渲染当前跨页（左页 + 右页）
  │
  ▼
【翻页】
  ├─ 点击 › (bookNext)  → _flipNext()  → 翻书动画（右翻）
  └─ 点击 ‹ (bookPrev)  → _flipPrev()  → 翻书动画（左翻）
        │
        ▼
  _startFlip() 翻页过渡 → transitionend → _msgBookSpread±1 → _renderBook()
  │
  ▼
【发布留言】
  填写昵称 + 内容 → 点击"发布留言"
        │
        ├─ 校验非空（否则 alert）
        ├─ 构造 {nick, text, time:今天}
        ├─ _saveComment() → unshift 到 localStorage
        ├─ 清空输入框
        └─ _msgBookSpread=1 → _renderBook()（留言即时上墙）
```

**留言卡片**：按昵称哈希生成渐变头像底色 + 首字母；HTML 转义防止 XSS。
